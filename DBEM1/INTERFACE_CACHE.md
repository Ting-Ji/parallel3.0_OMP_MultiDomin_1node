# 接口缓存（第 1 步）

`MultiDomainInterfaceCache` 在节点配对和物理初始化完成后、GMRES 求解开始时构建一次。Step0 串行及 pthread 接口组装、串并行比较、解回填和历史状态更新显式接收同一份 `const` 缓存，不再逐单元扫描接口列表。

`Get(element)` 返回只读记录：域、接口编号（外边界为 -1）、参考侧、物理节点、对侧单元/节点、参考单元/节点及 3×3 变换。A 侧为参考侧，A 侧与外边界保存精确单位阵，B 侧保存 `Q_B * Q_A^T`。面力符号仍由自由度映射处理。当前每单元只有一个物理节点。

缓存拥有数据，不保存坐标矩阵指针、线程编号、积分工作区、BCID 或组装结果。接口配对、节点编号或坐标系改变后必须重建；时间推进不修改缓存。未来接口 worker 和跨域任务可共享同一缓存，但仍须独立解决共享 BCID 和积分工作区问题。

原有公共装配和矩阵自检入口保持签名，独立调用时创建缓存并检查失败；求解器内部使用显式缓存重载，避免重复构建。非法归属、重复接口、未解析配对或缺失/非有限接口坐标矩阵会停止，不回退为搜索或单位阵。无接口模型不要求提供接口坐标矩阵。

验证命令（Windows Python/MSVC）：

```powershell
python DBEM1\tests\run_step1_cache_tests.py
# 可指定修改前保存的算例输出目录
python DBEM1\tests\run_step1_cache_tests.py --baseline <输出目录>
```

测试包含旋转坐标系、只读快照、缺失矩阵、重复归属及无接口情况，数值算例只用两域 5 步。构建及输出在 `validation_runs/step1_cache/`；默认使用本地第 0 步基线（若存在），否则报告基线比较未执行。默认版与诊断版结果、串并行矩阵、残差及接口约束始终检查。未运行大规模性能测试。
