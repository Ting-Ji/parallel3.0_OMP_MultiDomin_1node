# 平面单元精确波前积分接入

2026-11-03。默认启用，重新编译工程后生效。

## 调用流程

`GeoInit` 构建只读几何缓存。平面、直边、凸四边形进入精确分区；其他几何继续使用原路径。`NeedCal` 对适用单元采用保守距离分类；U/T1/T2 的 Judge、普通积分与 PW 入口使用相同的新积分器，防止完整受影响单元内部的 P/S 分界被跳过。未分型 T 入口分别计算 T1、T2 后相加。

对 U/T1，物理时间窗为 `[n dt,(n+1)dt]`；对 T2 为 `[(n-1)dt,n dt]`。收集两种波速乘时间端点得到的全部正分界距离，再按源点到平面的距离转换为圆半径。分割方向来自全部顶点与圆边交点；每个角度处重新求射线与四个有向半平面的交区间。5/9 点规则比较驱动全核块自适应细分，绝对项采用样本范数和单元特征尺度中的较大者。

核函数、当前线程的材料参数、法向和时间权重保持现有定义。初始自单元奇异积分由既有缓存提供，不交给普通积分器。几何准备在工作线程启动前完成；单元奇异初始化的可写临时数组改为线程局部，pthread 积分失败在所有工作线程汇合后向调用者报告。

## 验证

Windows Python 运行：

```text
python tools/test_wavefront_integration.py
python tools/smoke_wavefront_integration.py
python tools/smoke_wavefront_integration.py --one-thread
```

参考输入 `tests/wavefront_references.txt` 存储此前独立研究的 210 个核块。首行为数量，各行依次为案例名、四顶点平面坐标、源点离面距离、泊松比、时间步长、实际核时滞、核类型、参考特征尺度、九个矩阵分量。统一材料 E=20000、ρ=8，G=E/[2(1+ν)]；类型 0/1/2 分别代表 U/T1/T2。参考来自专题第二轮的高精度独立参考积分，覆盖薄支撑、偏心、近场、斜四边形、梯形与材料变化。本次直接编译实际项目源文件进行比较，同时逐项核对串行与双线程 Judge 入口、非奇异组合 T 入口和预算耗尽错误。

真实短时程包括多域求解路径下的单域 3 步、双域同材 5 步、双域异材 5 步。检查正常退出、状态文件存在及所有位移/面力有限；分别运行一、二线程检查结果。GMRES 与 RHS 单元回归独立执行，其预期的故障注入诊断不代表实际算例失败。

旧单域 GMRES 路径的 6 单元、3 步测试发生访问异常；使用修改前 HEAD 的源码另行编译，也在相同案例和阶段得到相同异常码 0xC0000005。本次不将其记为通过。默认 smoke 测试覆盖目前正常工作的多域求解路径；`--legacy` 可额外复现该既有问题。新波前入口的串行及双线程核块测试已经单独覆盖。

本批是核块与短时程接入验证。长时程精度、完整装配成本及工程规模性能仍需随后实测。

本次验收：210 个参考核块全部通过，最大误差/混合容差比为 `2.11563e-5`；串行与两个工作线程的核块逐项一致，组合 T 入口及预算耗尽检查通过，GMRES/RHS 回归通过。三类短时程均成功输出有限状态；一线程与二线程的位移、面力逐项相同（最大绝对差为 0）。记录见 `tmp/wavefront_integration/acceptance.json` 及同目录日志。

## 后续解析精度对照与保存状态

核块回归通过不代表完整物理解的误差降低。已完成的1000域100步、2000域100步与1000域1000步对比中，新方法均没有统一降低物理误差；1000步加载端均值相对L2从旧法13.2274%变为新法15.5167%，全边界三分量位移从15.9847%变为18.5526%。82单元、beta=0.6的小长杆中，轴向相对L2从13.3525%降为11.5103%，也没有达到高精度候选的预定目标。当前作为研究实现保存，不宣称精度或整体性能已优于原分片法。
