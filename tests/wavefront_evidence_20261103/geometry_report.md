# 几何覆盖新增验证（2026-11-03）

已完成：294 个设置 × 6 积分 = 1764 项。随机种子 20261109。

## 方法

从既有研究源文件逐字提取 `Context::ray` 与 `planeCells`，生成独立 C++ 测试程序。源文件 SHA256：47d50bb7939af567bae676e9c87aa44d4bd9266be585eb0a45c9006cc5b41498。测试不修改求解器。

六个积分：1、x、y、x²+y²、1/sqrt(x²+y²+0.05²)、径向分段常数（1,-0.7,1.3 循环）。径向均解析计算；角向比较 16/32/64 点及自适应 16/32 点。近边界距离在 (1e-14,1e-3) 时增加两端 2^-k 分级，k=1..40。后者为本次验证的求积加密，并非已接入生产求解器的优化。

独立参考：直角坐标竖向切片，逐边半平面求 y 上下界，与圆截取后沿 y 解析积分，再沿 x 用 QUADPACK 自适应积分；x 分点含顶点、圆边交点及圆的左右极值。绝对/相对容差均为 2e-12。

尺度化分母：A、AL、AL、AL²、A/0.05、1.3A；L=max(1,最大顶点距离)，A 为整个单元面积。近零量不以自身作分母。统一验收阈值 1e-9。

## 解读

未发现本批几何漏区或重区证据。一般位置固定点数已很准确，近边或近顶点时固定规则可遗漏窄的角向变化，需角向加密。有限实验不能代替全位置数学证明。现有 P/S 核矩阵及效率结论沿用之前研究，本批不声称完整求解器提速。

## 复现

Windows Python 3.12（numpy/scipy）运行 run.py；脚本调用本机 VS2022 C++ 编译器。run.py 生成实际提取源码 harness.cpp、build.log、全部几何参数和逐项结果 results.json、汇总 summary.json、native_output.txt。运行 deliver.py 进行解析与旋转检查并生成汇报页。全部工作在专题隔离目录，无提交或生产接入。
