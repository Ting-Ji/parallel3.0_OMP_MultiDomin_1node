# 去除精确积分路径的重复计算：接入与验证

日期：2026-11-04。实现工作区：codex/wavefront-reuse-20261104，基于622e2ef。当前主工作区gmres_RHS_openMP未切换。新提出的位移历史反馈根因调查保持暂停，本次仅完成此前授权的去重接入与验证。

## 实际改动

存档实现已经把射线裁剪与三角函数移出径向循环，本次没有将这一已有优化作为新增收益。新增：

- 线程私有的平面波前分区缓存，复用U(n)、T1(n)、T2(n+1)相同物理窗口的几何分区。
- 线程私有的整片保守界限缓存，复用Classify、Integrate及完整参数片评估之间相同源点—面元的距离/面积/Jacobian界限。
- 每层每线程至多两项，分区超过4096初始片时不缓存；保留不可变几何所有者，避免重新初始化和地址复用产生错误命中。
- 默认开启；编译时DBEM_WAVEFRONT_REUSE_PARTITIONS=0关闭新增复用。没有共享核结果、误差估计或自适应叶子队列，原采样点、权重与预算保持一致。

核心文件：DBEM1/wavefront_quadrature.cpp/.h、solver_policy.h。细节与构建方法见DBEM1/WAVEFRONT_REUSE.md。

## 正确性结果

1. 210个独立参考块全部通过。缓存开关输出的矩阵、误差估计、尺度、容差、自适应层数和核求值次数逐字节一致。
2. 覆盖重复调用、对齐T2窗口、源点和波速变化、同波速不同材料、时间窗变化、GeoInit重建、预算耗尽、容差变化、曲面路径及双线程隔离。
3. 开/关两种构建各自的既有GMRES和RHS回归均通过。
4. 82单元、56步、两线程，三组成对重复；328单元、112步、两线程，两组成对重复。共10次完整求解，同一网格所有运行的位移与面力CSV哈希完全相同，输入摘要完全相同。实际dt=.0021；全部输出有限，行数和时间步完整，所有当步独立真实残差通过1e-10。
5. 单域、双域同材、双域异材，分别1/2线程与缓存开/关，共12次短时程验证，各组全部物理分量精确相同。
6. 最终源文件摘要与两种实际构建一致，构建选项仅新增复用开关不同；运行EXE、输入和物理输出摘要全部经独立audit_wavefront_reuse.py复核。验收见acceptance.json。

这是保持已有离散解的优化，不代表原有物理误差被修复。没有开展已暂停的历史反馈根因调查，也没有修改时间递推、边界条件、核公式或原奇异积分。

## 重复工作确实减少，整程收益有限

上述核块复用/失效测试工作负载中，初始分区构造2100→861（减少59.0%），界限计算4465→2374（减少46.8%）；分别命中1239和2091次。该负载包含特意重复和失效调用，不能把降幅当成生产求解中的命中率或加速比。

配对测试交换先后顺序，保留全部原始计时；表中为求解含装配的中位数：

|规模|缓存关闭/s|缓存开启/s|比值（关闭/开启）|
|---|---:|---:|---:|
|82单元，56步，3组|9.637934|9.431851|1.02185|
|328单元，112步，2组|134.101008|133.840872|1.00194|

中等规模第1组135.426653→136.381971s，第2组132.775362→131.299772s；有快慢交叉，约0.2%的中位数差不能证明稳定加速。小算例约2%的差异也只描述本机这组三次实验，没有固定CPU频率或做统计显著性保证。

因此，**实现及正确性验证完成，新增复用确实削减重复几何工作，但尚无显著整程加速证据。** 不能把这次改动宣称为解决此前精确后端成本偏高的问题。核求值次数未减少；当前数据也不能唯一量化“剩余核计算占比”与“缓存管理开销”的份额。

此前仅复用分区的试实现（尚无界限缓存）中，82单元中位数9.6053→9.4763s、328单元136.9136→137.6248s，也没有稳定整程收益；原始记录保留在主项目tmp/wavefront_reuse_validation。本表和本目录验收均针对最后加入界限复用的版本，不混用前一版结果。
